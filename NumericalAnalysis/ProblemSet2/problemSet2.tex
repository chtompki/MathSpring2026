        % Problem 1
        \textbf{1.} Use the command \texttt{magic(n)}, for $n=100,200,300,\ldots,10^4$ to construct the magic square
        matrices of order $n$.
        Magic squares are defined as those matrices having entries for which the sum of the elements by rows, columns,
        or diagonals are identical.
        Then compute their determinants by the command \texttt{det()}.
        Use the command \texttt{cputime} to get the CPU time that is needed fore this computation.
        \textbf{Be patient, it may take around 10 minutes to compute these determinants.}

        Find a constant $C$ such that the computation time $t_n$ scales approximately as $t_n ~ Cn^3$.
        Plot your data and approximate scaling using \texttt{semilogy()}.
        Think back to the methods you learned for computing determinants in your Linear Algebra class.
        What method do you suspect Matlab is using and why?
        How can you be sure it isn't using cofactor expansion?
        \begin{solution}
            We begin by noticing that for any $A=\texttt{magic(n)}$ where $n$ is even, $\text{det}(A)=0$.
            So we are less concerned with keeping the valued of the determinants, and are more interested
            in the number of seconds that it takes to calculate the $i^{\text{th}}$-determinant.
            A sample of the code
            (given in file
            \underline{\href{https://github.com/chtompki/MathSpring2026/tree/main/NumericalAnalysis/ProblemSet2/ps2prob1.m}{ps2prob1.m}})
            that we are using follows as:
            \begin{verbatim}
determinants=zeros(1,100);
cpuTime=zeros(1,100);
for n=100:100:10000
    A = magic(n);
    tstart = cputime;
    det(A);
    cpuTime(n/100) = cputime - tstart;
end
plotN=1:100;
figure;hold on; semilogyi(plotN, 0.000008.*plotN.^3, '--x', plotN, cpuTime, '-x');
xlabel('Matrix Size (n/100)');
ylabel('Value');
legend('Cn^3','CpuTime');
title('Determinants and CPU Time vs. Matrix Size');
            \end{verbatim}
            Notice that around the determinant calculation we are taking the system time and doing a subtraction to get the
            duration of the determinant algorithm.
            The figure that we get from plotting the cputime follows in Figure \ref{problem1figure1}
            \begin{figure}[!ht]
                \centering
                \includegraphics[scale=0.4]{problem1figure1.png}
                \caption{Determinant Runtime by Matrix Size}
                \label{problem1figure1}
            \end{figure}
            Lastly we notice that for $C=2.5\times 10^{-5}$, which we found by fiddling around with the algorithm to get the value
            using the bisector method by hand so to speak.
        \end{solution}

        % Problem 2
        \noindent\textbf{2.} Consider the matrix $A = \left(\begin{matrix}201 & 199\\199 & 201\end{matrix}\right)$.
        \begin{enumerate}[label=(\alph*)]
            \item Compute the spectral radius of $\rho(A)$.
            \item Computer the condition number $K(A)$.
                  You may choose any natural matrix norm, but be sure to specify which one you are using.
            \item Assume some numerical method has been applied to obtain the approximate solution $\hat{x} = (-0.5,0.5)^\top$
                  to the system $Ax = B$ for $b = (-2,2)^\top$.
                  Use the residual $r=A\hat{x} - b$ and known inequalities to provide a bound on the norm of the
                  relative error $\frac{\|\hat{x} - x\|}{\|x\|}$.
            \item Find the exact solution to the above system (you may use any method you prefer, but show you work).,
                  Compare the relative error estimate from above to the actual relative error.
            \item In general, when can you expect the residual $r$ to provide a tight bound on the error?
        \end{enumerate}
        \begin{solution}
            For the problem generally we'll use the $L_2$-norm.

            (a) To compute the spectral radius $\rho(A)$, we go after the eigenvalues of $A$.
            So, let's compute the characteristic polynomial.
            \begin{displaymath}
                p(t) = \left|\begin{matrix}
                                 201-t & 199\\
                                 199 & 201 -t
                \end{matrix}\right| = t^2-402t-40401-39601 = t^2-402t+800.
            \end{displaymath}
            So we solve for $p(t)=0$, and we get the following roots $\lambda_1,\lambda_2$ from the quadratic formula:
            \begin{displaymath}
                \lambda_1,\lambda_2 = \frac{402\pm\sqrt{161604-3200}}{2} = \frac{402\pm 398}{2} = 2, 400.
            \end{displaymath}
            So for (a), our spectral radius follows as:
            \begin{displaymath}
                \rho(A) = \text{max}\{\lambda_1,\lambda_2\} = 400.
            \end{displaymath}

            (b) We'll continue to use the $L_2$-norm here. Notice that $A\in\text{symm}(\mathbb{R})$, so we know that
            the eigenvalues $\lambda_1,\lambda_2$ set up as:
            \begin{displaymath}
                \|A\|_2 = 400 \quad\text{and}\quad \|A^{-1}\|_2 = \frac{1}{2}.
            \end{displaymath}
            So by definition of $K(A)$, we have
            \begin{displaymath}
                K_2(A) = \|A\|_2\|A^{-1}\|_2 = \frac{400}{2} = 200.
            \end{displaymath}

            (c) We start with some matrix multiplication to see what our vectors $\hat{x},b$ from the problem statement
            give us. So we see that
            \begin{displaymath}
                \left[\begin{matrix}
                          201 & 199\\
                          199 & 201
                \end{matrix}\right]
                \left[\begin{matrix}
                          -0.5\\
                          0.5
                \end{matrix}\right]
                =
                \left[\begin{matrix}
                          201(-0.5) + 199(0.5)\\
                          199(-0.5) + 201(0.5)
                \end{matrix}\right]
                =
                \left[\begin{matrix}
                          -1\\
                          1
                \end{matrix}\right].
            \end{displaymath}
            So write the residual as
            \begin{displaymath}
                r = A\hat{x} - b =
                \left[\begin{matrix}
                          -1\\
                          1
                \end{matrix}\right] -
                \left[\begin{matrix}
                          -2\\
                          2
                \end{matrix}\right]
                =
                \left[\begin{matrix}
                          1\\
                          -1
                \end{matrix}\right]
            \end{displaymath}
            So we let the error be $\hat{x}-x$.
            Notice
            \begin{displaymath}
                r=A\hat{x} - b = A\hat{x} - Ax = A(\hat{x}-x).
            \end{displaymath}
            Also, we see that
            \begin{displaymath}
                \|\hat{x}-x\|\le\|A^{-1}\|\|r\|
            \end{displaymath}
        \end{solution}
