        (a) We went about completing this problem by writing the following code:
        \begin{tiny}
        \begin{verbatim}
function Q = gram_schmidt( X )
    % Q = gram_schmidt( X )
    % X is an d by n matrix
    % Q is an d by r matrix with 1 <= r <= n that is linearly independent
    % computes the Gram-Schmidt left decomposition matrix Q
    % By Rob Tompkins, 20260215
    [d,n] = size(X);
    m = min(d,n);
    R = zeros(m,n);
    Q = zeros(d,m);
    for i = 1:m
        v = X(:,i);
        for j = 1:i-1
            R(j,i) = Q(:,j)'*v;
            v = v-R(j,i)*Q(:,j);
        end
        R(i,i) = norm(v);
        Q(:,i) = v/R(i,i);
    end
    R(:,m+1:n) = Q'*X(:,m+1:n);
end
        \end{verbatim}
        \end{tiny}

        The code follows as:
        \begin{tiny}

function [R,U] = householderDecomposition(A)
    % Householder reflections for QR decomposition.
    % [R,U] = house_qr(A) returns
    % R, the upper triangular factor, and
    % U, the reflector generators for use by house_apply.
    % By Cleve Moler, October 3, 2016
    % https://blogs.mathworks.com/cleve/2016/10/03/householder-reflections-and-the-qr-decomposition/
    H = @(u,x) x - u*(u'*x);
    [m,n] = size(A);
    U = zeros(m,n);
    R = A;
    for j = 1:min(m,n)
        u = house_gen(R(j:m,j));
        U(j:m,j) = u;
        R(j:m,j:n) = H(u,R(j:m,j:n));
        R(j+1:m,j) = 0;
    end
end

function u = house_gen(x)
    % u = house_gen(x)
    % Generate Householder reflection.
    % u = house_gen(x) returns u with norm(u) = sqrt(2), and
    % H(u,x) = x - u*(u'*x) = -+ norm(x)*e_1.

    % Modify the sign function so that sign(0) = 1.
    sig = @(u) sign(u) + (u==0);

    nu = norm(x);
    if nu ~= 0
        u = x/nu;
        u(1) = u(1) + sig(u(1));
        u = u/sqrt(abs(u(1)));
    else
        u = x;
        u(1) = sqrt(2);
    end
end
        \end{verbatim}
        \end{tiny}

        % Problem 4
        \textbf{Exercise 4.} As specified in the guided lab we are working with the fact that for solving a system
        of lienar equations we can use the following breakdown because of our $QR$-decomposition:
        \begin{eqnarray*}
            \centering
            Ax & = & b \\
            QRx & = & b\\
            Q^{\top}QRx & = & Q^{\top}b \\
            Rx  & = & Q^{\top}b
        \end{eqnarray*}
        So for us to effectively solve our equations we have two mechanisms, the first being the decomposition,
        the second being solving the upper triangular matrix problem. So our solution which we have in files
        \href{https://github.com/chtompki/MathSpring2026/blob/main/NumericalAnalysis/GuidedLab2/problem4.m}{problem4.m}, and
        \href{https://github.com/chtompki/MathSpring2026/blob/main/NumericalAnalysis/GuidedLab2/qrSolve.m}{qrSolve.m}.

        The interesting bit is the implementation of ``qrSolve.m'' which follows as:
        \begin{tiny}
        \begin{verbatim}
function x = qrSolve(Q, R, b)
    % x = qrSolve(Q, R, b)
    % Q - an n by n matrix that is the left hand side of a QR decomposition
    % R - an n by n matrix that is the right hand side of the QR
    % b - the vector on the right hand side of our equation Xx=b or QRx = b
    % The goal here is to solve our linear set of equations relying upon a
    % QR decomposition. This is equivalent to writing an algorithm
    % for solving an upper triangular equation because our equation is also
    % seen as Q'QRx = Q'b => Rx = Q'b
    % by Rob Tompkins, 20260215
    n = length(b);
    V = Q'*b;
    x = zeros(n,1);
    x(n) = V(n)/R(n,n);
    for k=n-1:-1:1
        x(k) = (V(k) - R(k, k+1:n) * x(k+1:n)) / R(k, k);
    end
end
        \end{verbatim}
        \end{tiny}

        % Exercise 5
        \textbf{Exercise 5.} Generally we are concerned with the decomposition of
        $A\in\mathbf{M}_{m\times n}(\mathbb{C})$ into three matrices $U$, $S$, and $V$ such that
        \begin{displaymath}
            A = USV^*
        \end{displaymath}
        where $U\in\mathbf{M}_{m\times m}(\mathbb{C})$ with $U^* U=UU^*=I_m$ and $V\in\mathbf{M}_{n\times n}(\mathbb{C})$
        with $V^* V = VV^* = I_n$ and $S$ be an $m\times n$ matrix with
        \begin{displaymath}
            S = [s_{kl}]
            \begin{cases}
                \sigma_k & \text{ for } k = l\\
                0 & \text{ for } k \neq l
            \end{cases}
        \end{displaymath}
        with $\sigma_k \ge \sigma_{k-1}$ for $k=2,\ldots,r$.
        The number $r$ is the rank of $A$ and $r\le\text{min}\{m,n\}$.
        Note that the singular values $\sigma_k$ are positive real numbers and they are the eigenvalues of the
        hermitian matrix $A^* A$.
        Now this curiously provides us a mechanism for ``solving'' the equation $Ax=b$ despite the fact that $A$ is not
        a square matrix.
        Before we begin we want to define the following matrix $S^+$
        \begin{displaymath}
            S^+ = [s_{kl}]^+ =
            \begin{cases}
                \frac{1}{\sigma_k} & \text{ for } k = l\\
                0 & \text{ for } k \neq l.
            \end{cases}
        \end{displaymath}
        We can then proceed with the following algebraic manipulation to solve for $x$ in $Ax=b$
        \begin{eqnarray*}
            Ax  & = & b \\
            USV^* x & =  & b \\
            U^* USV^* x & = & U^* b\\
            SV^* x & = & U^* b\\
            S^+ SV^* x & = & S^+ U^* b\\
            V^* x & = & S^+ U^* b\\
            VV^* x & = & VS^+ U^* b\\
            x & = & VS^+ U^* b.
        \end{eqnarray*}
        So we now have a kind of solution for $x$.
